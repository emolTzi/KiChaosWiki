进入世界后，**首先按 `V` 键打开角色创建界面**。如果出现“Waiting for server data”提示，按ESC关闭后等几秒再按V。

> ⚠️ **特别提醒**：角色创建完成后，**一切选择（种族、职业、属性等）后续均可修改！所以不必过于纠结。

### 1. 选择种族

模组提供了6个种族可选：

| 种族        | 特点                                                      | 特点      |
| --------- | ------------------------------------------------------- | ------- |
| **人类**    | 最平衡，高耐力和气，但攻击偏弱                                         | 可改造成人造人 |
| **赛亚人**   | 攻击最强，但耐力和防御很低                                           | 形态最多    |
| **混血赛亚人** | 赛亚人的均衡版                                                 | 潜力最大    |
| **那美克星人** | 气功伤害全种族最高，物理偏弱                                          | 气伤加成高   |
| **冰冻恶魔**  | 高防御和高速度，伤害偏低                                            | 灵活的坦克   |
| **魔人**    | 属性综合最低，但有吸收和再生技能[](https://www.mcmod.cn/post/1491.html) | 难度最高    |

**新手建议**：推荐选择**赛亚人**或**混血赛亚人**，变身形态多，成长上限高，玩起来最有“龙珠”的感觉。

### 2. 选择能量类型

在角色创建的第二页，**务必将能量类型从“Natural”改为“Ki”（气）**

### 3. 选择职业

三个职业供你选择：

- **格斗家（Warrior）**：最高力量和生命，适合近战
    
- **气功师（Spiritualist）**：最高气和气功伤害
    
- **武道家（Martial Artist）**：力量和气功控制最平衡
    

**新手建议**：选择**武道家**最稳妥，不会偏科

### 4. 选择气焰颜色

最后选择你喜欢的 aura（气焰）颜色，确认后角色就创建完成了。

## 三、认识游戏界面

角色创建完成后，你的屏幕会出现新的UI：
- **右侧红色条** = 生命值（Health），点体魄可以提升上限
 
- **左上角银色条** = 气（Ki），使用气功技能需要消耗，点精神可以提高上限

- **左上角蓝色条** = 耐力值（Stamina）,每次攻击消耗，耗尽后无法出伤，自然恢复，点体魄可以提升上限
- 
- **左上角紫色条** = 气释放程度(0~100%)


再次按 `V` 键打开的就是**角色菜单（Character Menu）** ，在这里可以查看和升级你的属性[](https://www.minecraftxz.com/longzhuC/)。

属性说明[](https://www.minecraftxz.com/longzhuC/)：

- **STR（力量）** ：增加近战伤害
    
- **DEX（灵巧）** ：增加防御与速度
    
- **CON（体魄）** ：增加体力与耐力
    
- **WIL（意志）** ：影响气相关能力
    
- **MND（心智）** ：影响气和恢复
    
- **SPI（精神）** ：影响气上限

## 五、奇沌龙珠特色功能

### 1. 自定义形态变身系统

你可以在基础形态之上**自由搭配外观**，打造属于你自己的独特变身！

**添加自定义形态：**

1. 按 **`Y`** 键打开自定义形态菜单
2. ![[Pasted image 20260726185935.png]]
3. 点击右下角的 **「Configure」** 按钮
4. ![[Pasted image 20260726185951.png]]
5. 点击中间人物周围的任意**空栏位**
6. ![[Pasted image 20260726190001.png]]
7. 点击 **「Edit」** 按钮
8. ![[Pasted image 20260726190019.png]]
9. 在列表中选择你想添加的形态
10. ![[Pasted image 20260726190032.png]]
11. 点击 **「添加」** 完成,再点击右下角DONE![[Pasted image 20260726190055.png]]

**使用自定义形态：**

1. 按住 **`Y`** 键，在弹出的列表中选择你想变的形态
2. 选择成功后，**长按 `G` 键**即可变身自定义形态

> 💡 **提示**：自定义形态和原版形态不冲突，你可以随时切换使用。

---

### 2. 自定义技能系统

除了基础的气功技能，你还可以自由搭配**自定义技能**，打出自己的连招！

**装备技能：**

1. 按 **`E`** 打开背包
2. ![[Pasted image 20260726190127.png]]
3. 在背包界面左上角右侧![[Pasted image 20260726190135.png]]，倒数第二个图标![[Pasted image 20260726190152.png]]（**拳头图标**）![[Pasted image 20260726190157.png]]点击打开技能面板
4. 在技能面板中，将想要使用的技能**拖动到下方技能栏**中
5. 按 **`F1` / `F2`** 切换技能页
6. ![[Pasted image 20260726190221.png]]
7. 装备完成后，按 **`T`** 键释放当前选中的技能

> 💡 **提示**：多尝试不同技能搭配，找到最适合你的战斗风格！

### 3. 服务器快捷操作

| 按键 | 功能 |
| ---- | ---- |
| **`~`**（主键盘数字1左边的键） | 打开服务器菜单 |
| **`I`** | 隐藏/显示右侧面板 |

> `~` 键菜单包含服务器常用功能（商店、传送、领地等），建议多逛逛！
> `I` 键可以快速隐藏右侧DBC面板，方便截图或看风景~
